# Implementation Plan: Remove IsSilentSentinel and Always Deliver Final Output Text

## Overview
Per user directive, completely remove `IsSilentSentinel` across `aerial-brain` so that any final output text generated by the model/turn is always delivered to Discord, rather than being suppressed by internal wait regexes. Only truly empty text (`strings.TrimSpace(cleanText) == ""`) with zero attachments will skip Discord delivery.

## Proposed Changes

### `brain/pkg/runner/runner.go`
- Remove `silentWaitRegex` definition.
- Remove `IsSilentSentinel(stdout string) bool`.

### `brain/pkg/runner/runner_test.go`
- Remove `TestIsSilentSentinel`.

### `brain/pkg/session/session.go`
- Remove `silentWaitRegex` definition.
- Remove `isSilentSentinel(s string) bool`.
- In `ExtractFinalSubstantiveResponse`:
  Change:
  ```go
  if isSilentSentinel(trimmedContent) {
      return "", true, nil
  }
  ```
  To:
  ```go
  if trimmedContent == "" {
      return "", true, nil
  }
  ```

### `brain/pkg/session/session_test.go`
- Update `TestExtractFinalSubstantiveResponse_SilentSentinel`:
  Verify that when terminal content is `"wait for background task 123 to complete"`, it is delivered as substantive (`isSilent == false`, `finalText == "wait for background task 123 to complete"`).
  Rename/update test description to `TestExtractFinalSubstantiveResponse_WaitNoticesDelivered`.

### `brain/pkg/queue/worker.go`
- At line 1769:
  Replace:
  ```go
  isSilent := runner.IsSilentSentinel(cleanText) && len(attachments) == 0
  ```
  With:
  ```go
  isSilent := strings.TrimSpace(cleanText) == "" && len(attachments) == 0
  ```
